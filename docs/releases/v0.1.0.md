# BasaltVR 0.1.0 developer preview

This is the first public developer preview of BasaltVR.

## Download

Download `BasaltVR-0.1.0-macos-arm64.zip` and its matching `.sha256` file from the assets attached
to this release. Verify the archive before opening it:

```sh
shasum -a 256 -c BasaltVR-0.1.0-macos-arm64.zip.sha256
```

The app is built for Apple Silicon and requires macOS 14 or newer. It is ad-hoc signed, not
notarized. macOS may require using **Open** from Finder's contextual menu the first time.

## Important preview limitations

- This is an engineering preview, not a turnkey consumer installer.
- The archive does not redistribute Wine, ALVR, OpenComposite, BlackHole, or games.
- A complete game setup still requires the pinned Wine/DXMT developer prerequisites described in
  the repository's bottle guide.
- The OpenXR runtime is experimental and non-conformant.
- Beat Saber is the narrow compatibility target; general PCVR support is not claimed.

## Included

- `BasaltVR.app`, `basalt-streamer`, and `basaltctl` compiled for Apple Silicon.
- The bundled CLI automatically locates its packaged support files when run outside a source
  checkout.
- Basalt's OpenXR runtime and DXMT handoff artifacts when the release was built from a fully
  prepared checkout.
- Setup, bottle-management, and architecture documentation.
- License and third-party notices.
